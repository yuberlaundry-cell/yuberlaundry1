# **App Name**: Yuber Laundry

## Core Features:

- Public Marketing Site: Landing page with service overview, pricing, FAQs, and city selector.
- Consumer Portal: Booking flow, order tracking, payment management, promotions, and referrals.
- Business Portal: Admin dashboard, employee management, business orders, reports, and billing.
- Driver Portal: Job lifecycle management, earnings overview, and support access.
- Laundromat Portal: Order processing, resource management, and staff overview.
- Superadmin Portal: Global dashboard, entity management, order management, financials, tenant configuration, and staff audit.
- Help Center: FAQ chatbot powered by generative AI to answer the common questions

## Style Guidelines:

- Primary color: Deep sky blue (#4975f5) to convey trust and reliability.
- Background color: Light gray (#f0f2f7) for a clean and modern look.
- Accent color: Purple (#7149f5) for highlighting key actions.
- Headline font: 'Space Grotesk', a sans-serif, for headlines
- Body text font: 'Inter', a sans-serif, for body text.
- Code font: 'Source Code Pro', a monospace font, for code snippets.
- Simple, recognizable icons for navigation, statuses, and actions.
- Responsive layout with breakpoints for phones, tablets, and desktops; reusable layout shells for each portal.
- Subtle animations for transitions and loading states.
